<p>Компания производит и поставляет Фрезерные станки с ЧПУ по дереву для современных мебельных фабрик, Фрезерные станки с ЧПУ по камню для камнеобрабатывающих цехов.</p>
<p>В наличии Лазерные станки ЧПУ с модулем резки труб, металлообрабатывающие станки – Листогибы с ЧПУ.</p>
<h3 class="section-title">Ассортимент компании «WoodLand» это:</h3>
<ul class="mb-5 ms-md-5">
	<li class="mb-3">Оптоволоконные лазерные станки для резки металла.</li>
	<li class="mb-3">Отоволоконное лазерное сварочное оборудование.</li>
	<li class="mb-3">Фрезерные и токарные станки с ЧПУ для металлообработки.</li>
	<li class="mb-3">Листогибы</li>
	<li class="mb-3">Фрезерные станки с ЧПУ по дереву, пластикам, композитным материалам и камню.</li>
	<li>Оборудование для производства мебели (форматно-раскроечные, сверлильно-присадочные, кромкооблицовочные станки)</li>
</ul>
